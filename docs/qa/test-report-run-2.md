## Важные ограничения / несогласованности тестирования

- **DOC2-047 Passed против PLAN2-029 Failed:** общая проверка редактирования не подтверждает конкретно изменение длительности; уточнить критерии и связать кейсы.
- **RESP2-004/010 Passed против MAP2-038/039 Failed:** техническая доступность на мобильном ≠ эргономика расположения контролов; разные критерии.
- **PLAN2-026 Passed против DOC2-029 Failed:** расчёт пешего времени может работать без отображения документированных расстояний.
- **TICK2-052:** браузерный Back обычно не обязан закрывать модалку, если она не представлена отдельной записью истории; не фиксировать как баг до согласования.
- **TICK2-057/RESP2-035:** для нативных checkbox стандартная клавиша переключения — Space, а не Enter; проверить тип элемента до окончательного решения.
- Результаты сенсорного взаимодействия MAP2-027–029 отмечены Passed; **реальное устройство не подтверждено** (может быть эмуляция).
- Количество 466 здесь относится к *обновлённому* набору второго прогона с собственными ID, а не к исходным идентичным 466 тестам.
