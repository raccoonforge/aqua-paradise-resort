## Различия с прототипами

- В Hero видны прямоугольные кнопки из согласованной системы. В шапке рядом с «Планировщиком» остаётся прямой переход к карте. Полоса общего референса Hero показывает раннюю навигацию, поздняя версия проверена отдельно.
- В журнальном развороте HTML-текст переносится по своим метрикам. Почтовый штамп отрисован с утверждённым знаком курорта.
- У билетов сохранены реальные проектные иллюстрации и данные. Их ракурсы, названия и типографика отличаются от вымышленных билетов на прототипе.
- На табло показаны действительные варианты интересов и сводка состава. Прямоугольная кнопка и разметка переключателей отличаются от декоративных подписей в PNG.
- В подвале стоят действующие ссылки и служебный текст демонстрационного сайта. Макет содержит пиктограммы соцсетей и правовые ссылки без соответствующих назначений в проекте.
