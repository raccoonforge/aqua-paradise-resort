## Что считать Failed
- Не воспроизводится ожидаемое поведение.
- В консоли — ошибка.
- Несоответствие требованиям.
- Регрессия в ранее работавшей функции.

## Что считать Blocked
- Невозможно проверить из-за отсутствия ассетов/данных.
- Зависит от NC-*.
- Требует устройства/браузера, которого нет в наличии.

## Что считать Passed
- Поведение соответствует ожидаемому.
- Нет новых ошибок в консоли.
- Нет визуальных дефектов, кроме Visual Pending.

## Acceptance gates перед «готово к релизу»
1. Нет Critical.
2. Нет High.
3. Все Medium либо Fixed, либо обоснованно переведены в Needs Clarification.
4. `npm run build` — зелёный.
5. GitHub Actions — зелёный.
6. Ручной smoke на 320, 375, 768, 1440.
7. Ручной smoke в Chrome, Edge, Firefox (по возможности).
8. Ручной smoke на реальном устройстве (Android/iOS) — минимум 1.
9. Все NC-* имеют решение или явное «вне scope».
10. Все Visual Pending задокументированы.

- Скриншоты каждого Failed.
