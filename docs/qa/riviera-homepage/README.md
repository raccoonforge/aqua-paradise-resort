## Запуск

Проверено с Node.js 24. Команды выполняются из корня проекта.

```sh
npm ci
npm run dev
```

Открыть адрес Vite с базовым путём `/aqua-paradise-resort/`. Для проверки production-версии выполнить `npm run build`, затем `npm run preview`. Существующая маршрутизация использует адреса вида `#/attractions?ride=skyfall` и `#/planner`.

## Источники оформления и данных

Hero, терраса, знак с пальмой и девять отдельных видов зон взяты из проектной ветки ретродизайна. Изображения Skyfall (ART‑11 v2), Poseidon's Descent (ART‑12), Stormbreaker (ART‑06) и Crystal Passage (ART‑13) взяты из проектной коллекции `docs/design/review` ветки `feat/premium-redesign`. Для билетов подготовлены уменьшенные WebP с печатной обработкой в интерфейсе. Локальные шрифты Allura и Libre Baskerville сопровождаются лицензиями OFL в `src/assets/retro/fonts/`.

Названия, интенсивность, возраст и минимальный рост привязаны к каталогу аттракционов. Описания и адреса девяти зон общие с их внутренней страницей. Для полного планировщика компания задаёт исходный состав гостей. Значения возраста и роста доступны для проверки и изменения до построения маршрута.
