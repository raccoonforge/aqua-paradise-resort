## Детализация только при необходимости

- UX по страницам: `aqua-paradise-{homepage,zones,attractions,hotel,visit,tickets,planner}-blueprint.md`.
- География и тематические планы: `aqua-paradise-island-masterplan.md` и файлы `*-site-plan.md`.
- История мира курорта: [Project Bible](./project-bible.md).
- Существующие кодовые эксперименты: `src/data/island-geography.ts`, `src/data/island-parcels.ts`, `src/data/island-transport.ts`. **Они не синхронизированы автоматически с v0.4** — при создании карты сначала провести адаптацию модели, а не параллельно использовать расходящиеся координаты.

## Старые версии и исследования — НЕ брать в приложение напрямую

`data/island-geometry-concept-v0.1.json`, `data/island-zone-partition-experiment-v0.2.json`, `data/island-landuse-grid-study-v0.3.json`, `data/island-access-graph-draft-v0.1.json`, `data/island-access-graph-draft-v0.2.json` и связанные SVG/аудиты хранят историю работы. **Не удалять или переносить без проверки ссылок и кода.** Сеть Paradise Loop пока лишь топологическая концепция; готового для ETA дорожного графа нет.

## Правила организации

1. Имена путей и идентификаторы в коде — английские, стабильные.
2. Русский — основной язык рабочих спецификаций и текста сайта; собственные названия зон сохраняются на английском.
3. Английская версия нужна для **публичной документации портфолио** (`README.en.md`, затем при необходимости англоязычные краткие описания страниц), **не для каждого** JSON, TS, SVG или технического черновика.
4. Для UI-переводов — отдельные словари `ru`/`en`, а не два независимых набора геометрии/цен/правил.
5. Одна актуальная версия машинных данных на назначение. Изменения оформлять коммитами, а исследования маркировать `draft` / `experiment` / `legacy`. Не переписывать прежние решения молча.
6. Перед изменением существующего кода проверять его импорты и тесты; старые файлы не считать автоматически устаревшими лишь по дате.

**Следующая организационная работа:** инвентаризация ссылок на старые данные, синхронизация Master Blueprint с поздними решениями и безопасное перемещение архивных черновиков с обновлением относительных ссылок. Это ещё не выполнено.
