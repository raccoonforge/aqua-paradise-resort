# Aqua Paradise Island Resort — Website Requirements

**Версия:** 0.1  
**Статус документа:** В разработке  
**Задача Jira:** APR-4  
**Основа:** Project Bible v0.2

## 1. Назначение сайта

Aqua Paradise Island Resort — демонстрационный адаптивный веб-сайт вымышленного островного курорта с аквапарком, гостиничным комплексом и интерактивными сервисами.

Сайт предназначен для презентации курорта, знакомства с тематическими зонами, планирования посещения, расчёта стоимости билетов и демонстрационного бронирования проживания.

Все цены, бронирования и сведения о доступности услуг используются исключительно в демонстрационных целях.

## 2. Целевая аудитория

Основные категории пользователей:
- Семьи с детьми.
- Пары и индивидуальные путешественники.
- Любители экстремальных водных аттракционов.
- Посетители, предпочитающие спокойный отдых.
- Гости гостиничного комплекса.
- Пользователи мобильных устройств.

Интерфейс должен быть понятным для посетителей с разным уровнем технической подготовки.

## 3. Формат проекта

Проект представляет собой полноценный адаптивный сайт курорта с демонстрационными интерактивными сервисами.

Разработка выполняется поэтапно.

### 3.1. MVP

В первую версию входят:
- Главная страница.
- Каталог тематических зон и аттракционов.
- Интерактивная карта острова.
- Калькулятор билетов.
- Планировщик посещения.
- Информация о транспорте и правилах посещения.
- Адаптивная навигация.

### 3.2. Последующее расширение

Во вторую версию входят:
- Каталог гостиничных номеров и вилл.
- Сравнение гостиничных тарифов.
- Демонстрационное бронирование проживания.
- Дополнительные гостиничные услуги.

Личный кабинет и реальные платёжные операции не входят в текущий объём проекта.

## 4. Предварительная структура сайта

### 4.1. Главная страница

Адрес: `/`

Содержит:
- Презентационный блок курорта.
- Краткую информацию об острове.
- Обзор тематических зон.
- Преимущества курорта.
- Информацию об отеле.
- Переходы к карте, билетам и планировщику.

### 4.2. Тематические зоны

Адрес: `/zones`

Содержит:
- Каталог девяти тематических зон.
- Карточки зон с изображениями и описаниями.
- Фильтрацию по типу отдыха.
- Переходы к подробной информации.

### 4.3. Страница тематической зоны

Адрес: `/zones/:slug`

Содержит:
- Название и описание зоны.
- Изображения.
- Перечень аттракционов и объектов.
- Информацию об ограничениях, если применимо.
- Ссылку на расположение зоны на карте.

### 4.4. Интерактивная карта

Адрес: `/map`

Содержит:
- Схематичное изображение острова.
- Отображение тематических зон.
- Выбор зоны на карте.
- Информационные карточки объектов.
- Переходы к подробным страницам.

### 4.5. Билеты

Адрес: `/tickets`

Содержит:
- Выбор даты посещения.
- Выбор категорий и количества посетителей.
- Выбор типа билета.
- Дополнительные услуги.
- Автоматический расчёт стоимости.
- Демонстрационное итоговое предложение.

### 4.6. Планировщик посещения

Адрес: `/planner`

Содержит:
- Выбор предпочтений посетителя.
- Выбор интересующих тематических зон.
- Учёт состава группы.
- Формирование предварительного плана посещения.
- Отображение выбранных объектов и рекомендаций.

### 4.7. Транспорт и правила посещения

Адрес: `/visit`

Содержит:
- Способы прибытия на остров.
- Информацию о Paradise Loop.
- Правила посещения.
- Сведения о безопасности.
- Часто задаваемые вопросы.

### 4.8. Гостиничный комплекс

Адрес: `/hotel`

На этапе MVP содержит презентационную информацию о Paradise Grand Hotel & Villas.

В дальнейшем дополняется каталогом номеров, тарифами и демонстрационным бронированием.

## 5. Общие требования

- Сайт должен корректно отображаться на компьютерах, планшетах и смартфонах.
- Основные разделы должны быть доступны через понятную навигацию.
- Интерактивные элементы должны иметь визуальную обратную связь.
- Формы должны проверять корректность введённых данных.
- Пользователь должен получать понятные сообщения об ошибках.
- Демонстрационные операции не должны создавать реальные заказы или платежи.
- Контент должен соответствовать Project Bible v0.2.
- Интерфейс должен учитывать базовые требования доступности.
