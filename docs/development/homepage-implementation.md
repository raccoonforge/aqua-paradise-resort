# Главная страница: реализация и проверка

Ветка: `feat/homepage-resort`. Источники: `docs/pages/homepage.md`, реестр `docs/source-of-truth.md`, документы `docs/master/`. Изменения не объединены с main.

## Реализовано

- Центрированный статичный Hero с дословными утверждёнными текстами. Компонент `Hero` принимает необязательный `introVideo`: muted/playsInline, пропуск, завершение и ошибка возвращают статичный фон, повтор в сессии подавляется. При reduced-motion, Save-Data или недоступном sessionStorage используется постер. Готового видео нет; согласованное видео должно завершаться ракурсом постера. Псевдоспуск не используется.
- Четыре полароида: указатель/свайп, нажатие/Enter/Space и «Раскрыть всё», сохранение снимков вокруг информации, повторная сборка. Прокрутка остаётся доступной, информация и фотографии разведены на телефонах и планшетах.
- Девять зон: большая сцена, описание и факты слева, горизонтальная лента, стрелки, свайп, `aria-pressed`, ссылка `/zones?zone=...`.
- Четыре аттракциона: scroll-snap карусель, стрелки, клавиатура, нативный touch-scroll. Возраст, рост, интенсивность, сопровождение и расписание взяты из website-requirements §§7.7.4–7.7.6.
- Мультивыбор интересов, три фото-карточки дня, сброс, передача `interests` в `/planner`. Это явно обозначенная рекомендация без расчёта маршрутов, очередей и допуска гостей.
- Deep Ocean Footer; Header с двумя dropdown, стеклянным состоянием при прокрутке и мобильным native dialog справа, аккордеонами, блокировкой прокрутки, Escape, возвратом фокуса и закрытием через фон.
- IntersectionObserver для одноразовых reveal, reduced-motion, семантические области и названия элементов управления, noscript-информация.

## Медиа

`public/media/*.webp` — локальные оригинальные сгенерированные иллюстрации вымышленного курорта, не фотографии существующего места. Hero подготовлен отдельно в 1536×1024, сцены зон — из согласованной по стилю сетки, отель и Crystal Passage — из отдельной серии. Полноэкранные сцены зон имеют исходное разрешение около 512×341; для финального production art direction желательно заменить их отдельными изображениями большего разрешения. `brand.webp` — уменьшенная WebP-копия существующего утверждённого логотипа. Оригиналы проекта сохранены. Внешних runtime-запросов к фотохостингам нет.

## Повторная проверка

```bash
npm ci
npm run build
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
# В текущей облачной машине уже установлен Chromium:
AQUA_ARTIFACT_DIR=/workspace/artifacts CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Playwright запускает Vite автоматически, либо использует уже запущенный сервер на 5173. По умолчанию снимки находятся в `/tmp/aqua-screenshots`; `AQUA_ARTIFACT_DIR` задаёт каталог артефактов. Тесты проверяют все основные механики, desktop 1440px, эмуляцию iPhone 13, 360px, планшет 768px, reduced-motion, загрузку изображений и отсутствие исключений JS. Эмуляция не заменяет проверку на физических iOS/Android и в Safari/Firefox.

Пройдено 8 браузерных тестов (4 сценария × 2 профиля). Дополнительный аудит axe WCAG A/AA на 1440, 768 и 390 px не обнаружил нарушений в проверенном раскрытом состоянии главной; это не сертификация полной доступности.

Сборка, линтер и четыре существующих проверки геометрии/контрактов v0.4 проходят. `/map` и десять её меток проверяются браузерными тестами. Источники геометрии, компонент и CSS карты не изменены.

## Границы

Внутренние каталоги, билеты, отель, посещение и полный планировщик в исходном проекте отсутствуют. Утверждённые ссылки сохранены; вместо ошибочного показа главной на этих путях выводится явное сообщение «В разработке». Это не реализация внутренних страниц. Реальные платежи, бронирования, ETA и проверенная маршрутизация не добавлялись.

Предпросмотр в onboarding UI недоступен: этот интерфейс не поддерживает localhost-ссылки. Для локального просмотра: `npm run dev`. Скриншоты подготовлены отдельно. Публикация и push в GitHub не выполнялись.
