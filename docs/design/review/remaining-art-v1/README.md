## Метод и сохранность цвета

Использованы полные утверждённые промпты ART-05–15 из [художественной концепции](../../homepage-art-direction.md). Для всех генераций приложены существующий Ocean Bay Hero и сравнительный лист утверждённых ART-01–04 как референсы палитры, натуральных материалов и общего визуального мира. География и предметные ограничения взяты из соответствующих PHOTO-ТЗ и site-plan, перечисленных в концепции. Новые сцены локальны: спорные взаимные положения объектов и обзор всего острова не восстанавливались.

Дополнительные производственные указания к промптам: только один независимый кадр 4:3; без подписей и рамок; не копировать композиции референсного листа; сохранить заданное время суток; фотографически достоверные материалы, оптика, свет и масштаб; без очевидного CGI и игрового рендера. Для концепт-арта — кинематографическая постановка при натуральных фактурах; для цифровой живописи — деликатная мягкость дальнего плана; для matte painting — атмосферная зелёная даль и достоверный передний план. Механизмы Skyfall, Poseidon и разделённые водные объёмы Crystal уточнены отдельно. Tidal Drop подготовлен как локальный художественный кандидат по текстовому описанию, без точных инженерных размеров и без моря в кадре.

Все 11 PNG скопированы **байт в байт из нативных результатов генератора**. Совпадение копий проверено SHA-256. Нет апскейла, ретуши, LUT, запечённой CSS-коррекции, дополнительной десатурации, затемняющего слоя или цветового фильтра. Палитра и освещение сформированы самой генерацией согласно промпту. Формулировка «без цветокоррекции» означает сохранение результата генератора, а не отсутствие художественного выбора цвета.

Утверждённая коррекция сайта (`saturate(.78) contrast(1.10) brightness(.90)` и бирюзовый слой) остаётся в CSS и к новым файлам сейчас не подключена. Общий лист тоже показывает ART-01–04 без их CSS-фильтров, чтобы корректно сравнивать исходники. Финальное поведение с фильтрами и адаптивные кропы проверяются отдельным этапом после художественной приёмки.
