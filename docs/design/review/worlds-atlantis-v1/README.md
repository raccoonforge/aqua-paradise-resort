## Точная причина отсутствия фоновой сцены

В исходной версии React создавал девять `.apr-worlds__backdrop` с валидными изображениями `HomeArtwork`, но их общий родитель был скрыт правилом из `src/components/home-artwork.css`:

```css
.apr-home .apr-worlds__backdrops { display: none; }
```

Правило осталось от прежнего Living Atlas, где использовалась отдельная арочная иллюстрация. Новый полноэкранный прототип в `src/midnight-obsidian.css` задавал этому контейнеру `position`, `inset`, `z-index` и `overflow`, но не восстанавливал `display`. В итоговом каскаде родитель оставался `display:none`.

Это воспроизведено в браузере **до редактирования кода**. При viewport 1440×1000 frame имел размеры 1440×1000, а backdrops, активная сцена и её изображение — 0×0. У активной сцены была `opacity:1`, но отрисовать её было невозможно из-за скрытого родителя. `isolation:isolate` у frame работал; сам по себе `z-index:-1` не был причиной исчезновения. Overlay shade был виден, и через прозрачный frame просматривался общий Midnight Obsidian.

Контрольный эксперимент: временно включён **только** `display:block` через браузерный stylesheet. Существующий файл декодировался (`complete:true`, `naturalWidth:1448`) и изображение появилось без изменения URL, `z-index`, `isolation`, размеров frame или перекрывающих слоёв. Его увеличенные размеры 1476×1025 соответствовали прежнему `transform:scale(1.025)`. Ошибок JavaScript при воспроизведении не было. Сбой был вызван скрывающим CSS, а не отсутствующим файлом, загрузкой или нулевой высотой самой секции.

## Исправление и новая композиция

Удалено устаревшее `display:none`. Добавлен отдельный `src/worlds-immersive.css`, ограниченный `.apr-home .apr-worlds--immersive`: явный `display:block`, положительные размеры и последовательность слоёв внутри изолированного frame:

| Слой | z-index | Назначение |
|---|---|---|
| `.apr-worlds__backdrops` | 0 | Новая панорама; pointer-events:none |
| `.apr-worlds__shade` | 1 | Плавное затемнение под текстом |
| `.apr-worlds__content` | 2 | Существующие тексты и CTA |
| `.apr-worlds__dock` | 3 | Горизонтальная навигация |

Frame занимает минимум 100svh. Панорама имеет явные размеры, `object-fit:cover`; кадрирование на desktop — `66% 48%`, на mobile — `78% center`. Вертикальная маска слоя панорамы мягко открывает неизменённый общий Midnight Obsidian по верхнему и нижнему краю. Градиенты и мобильная адаптация применены средствами CSS; исходник не затемнялся программно. Для navigation tabs задана фиксированная flex-база, чтобы intrinsic-размер растрового img не растягивал мобильную миниатюру. Dock оставляет место существующей плавающей кнопке «Наверх».

В React панорама импортируется непосредственно из `src/assets/worlds/atlantis-realm-panorama.webp`. Это WebP-производная исходника, 1672×941, quality 94, без изменения палитры и размера. Компактный файл используется и для миниатюры Atlantis; прежний `ART-05` в этой сцене больше не используется. Внутри `#worlds` только два img, оба с новым источником; ни ART-01–15, ни Hero, ни другие фотографии сайта там не подключены.

### Согласованное временное поведение навигации

Пользователь отдельно запретил сохранение прежних изображений в остальных восьми сценах и подтвердил временный переход их кнопок на страницы соответствующих зон. Поэтому на первом этапе:

- Atlantis Realm остаётся единственной фоновой сценой с новой эксклюзивной панорамой.
- Все девять кнопок сохранены в горизонтально прокручиваемой ленте. У Atlantis новая миниатюра, у остальных — номерные маркеры средствами HTML/CSS, без фотографий и SVG.
- Кнопки остальных восьми зон открывают существующий маршрут `#/zones?zone=<slug>`; панорама Atlantis не выдаётся за среду другой зоны.
- «Следующий мир» открывает следующую зону Eden Gardens по тому же временному правилу.
- «Подробнее о зоне» по-прежнему ведёт в Atlantis Realm, «Выбрать билет» — в билеты. Существующие тексты, названия и описания зон сохранены.

Пустые фоновые сцены не создаются. После приёмки Atlantis остальные восемь получат собственные эксклюзивные панорамы и затем смогут переключать фон внутри блока.

## Художественный и географический контроль

Новая генерация выполнена с нуля: без исходных изображений ART-01–15, Hero или других фотографий сайта в качестве основы и без их повторного использования. Визуальный ориентир задан текстовым описанием композиции из поручения: тихая тёмная левая часть, монументальные достопримечательности в центре и справа. Новых восьми панорам не создано.

Сцена — локальный вид внутренней северо-западной Atlantis Realm: колоннада, центральная площадь затерянного города, ограниченные искусственные водоёмы, мост, ступенчатые водопады и поднятый храмовый старт Poseidon с фрагментом закрытой трубы. Трасса уходит за архитектуру, не обещая выдуманного полного маршрута. В кадре нет моря, перенесённых из других зон аттракционов, отеля или горок с морским финишем. Tidal Kingdom и Crystal Passage не собраны в спорную общую панораму. Архитектура остаётся художественной интерпретацией канонических признаков, без заявленных точных инженерных размеров.

Luxury Cinematic выражен правдоподобными материалами и дневным светом, глубокими бирюзовыми тенями, естественной тропической зеленью и мягким золотистым светом на камне. Масштаб создают несколько планов террас, колоннад и малые фигуры посетителей. Исходник сохранён отдельно; финальная художественная приёмка ещё не получена.
