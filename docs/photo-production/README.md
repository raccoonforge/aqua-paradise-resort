# Производство фотографий Aqua Paradise Resort

Завершённый фотоаудит для дизайна Midnight Obsidian. Исходный снимок проекта: `dd072b7440819280df8ba8d04f3d6ba8a9351bc6`, ветка `feat/premium-redesign`. Материалы сохранены без пересмотра технических заданий; скорректированы только внутренние ссылки при переносе.

## Структура

- [Полный аудит](full-audit.md): методика, каталог, матрица, география, противоречия, план производства, фотографический стандарт и нерешённые вопросы.
- [Каталог CSV](photo-catalog.csv): 64 уникальных ТЗ `APR-PHOTO-001` — `APR-PHOTO-064`.
- [Матрица CSV](placement-matrix.csv): 210 строк размещений со статусами `current`, `document`, `optional`.
- [Индивидуальные ТЗ](briefs/): 64 Markdown-документа с сюжетами, композицией, кадрированием, источниками и будущими промптами.

## Статус и дальнейшая работа

Аудит завершён; фотографии ещё не созданы. Оценка составляет 52 исходника для текущих 125 логических размещений и 59 для минимального документированного объёма 205 размещений; ещё 5 сюжетов необязательны. Переиспользование зависит от проверки кадрирования.

Сначала согласовать зафиксированные географические противоречия и недостающие объектные референсы, затем отдельно согласовать генерацию. Производство начинать с главной по плану полного отчёта. Подготовка фотографий и их внедрение — отдельные этапы; существующие художественные фоны Midnight Obsidian сохраняются. Публикация аудита не разрешает изменение сайта или генерацию изображений.

## Дополнительные материалы аудита

Исходная рабочая папка: `/workspace/work/photo-audit/`. Упоминания `evidence/`, JSON, отдельных вспомогательных отчётов, HTML и ZIP внутри сохранённого текста относятся к этому исходному комплекту. Эти вспомогательные файлы не включены в настоящую публикацию. В частности, `evidence/mini-planner-bindings.csv` содержит 45 связей для 15 сценариев; ссылка на него ведёт к этому пояснению, а не к подменённому файлу. Допустимые ID фотографий для динамических шаблонов сохранены в поле `allowed_photo_ids` матрицы CSV, а обратные связи — в `dynamic_home_templates` каталога CSV.

Фотографический стандарт полностью включён в [полный отчёт](full-audit.md#универсальный-фотографический-стандарт). Все географические противоречия, ограничения и нерешённые вопросы сохранены в исходном виде. HTML-версии, поисковый индекс, ZIP и временные файлы не публикуются.
